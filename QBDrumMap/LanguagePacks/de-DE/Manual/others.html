Informationen zur automatischen Interpolation von Artikulationen

Beim Konvertieren von MIDI oder Erstellen einer zugeordneten Drum-Map wird für jede Drum-Map eine Artikulations-Map erstellt und die Tonhöhenkonvertierung basierend auf diesen Informationen durchgeführt.

Wenn einer Artikulation keine Tonhöhe zugewiesen ist, wird gemäß den folgenden Regeln eine alternative Tonhöhe eingefügt.

  1. Wenn die Artikulationsliste für jeden Drum-Part von oben nach unten undefiniert ist, geben Sie die vorherige Tonhöhe ein.
  2. Wenn die Artikulationsliste für jeden Drum-Part von unten nach oben undefiniert ist, füllen Sie die vorherige Tonhöhe aus.
  3. Nach der Ausführung von 1.2. Wenn es oben noch nicht definiert ist, geben Sie die Tonhöhe der Artikulation ein, die auf Komplement eingestellt ist.

Gemäß den oben genannten Regeln erfordern Drum-Part-Artikulationen mindestens eine Tonhöhenzuweisung.
