Liste bearbeiten

Informationen zum Bearbeiten des Listenanzeigebereichs auf jeder Plug-In-, Part- und Artikulationsseite

  • Klicken Sie, um eine Zeile auszuwählen, verwenden Sie die Steuertaste, um Auswahlen hinzuzufügen, und verwenden Sie die Umschalttaste, um einen Bereich auszuwählen
  • Löschen Sie die ausgewählte Zeile, indem Sie die Entf-Taste drücken, während eine ausgewählte Zeile vorhanden ist
    *Bei Stellplatzliste löschen
  • Funktionen der oberen Tasten
    • +: Eine Zeile hinzufügen
    • ⇧: Verschiebt die ausgewählte Zeile an den Anfang
    • ↑: Verschiebt die ausgewählte Zeile um eine Zeile nach oben
    • ↓: Verschiebt die ausgewählte Zeile um eine Zeile nach unten
    • ⇩: Verschiebt die ausgewählte Zeile an das Ende
  • Doppelklicken Sie auf eine Zelle oder drücken Sie die Taste F2, um in den Bearbeitungsmodus zu gelangen.

When you have unsaved changes

If a map has unsaved edits when you create a new map, open another file, or close the application, a confirmation appears.

  • Save: The operation continues after saving succeeds. If saving is canceled or fails, the operation is canceled.
  • Don't Save: The edits are discarded and the operation continues.
  • Cancel: The edits are kept and the operation is canceled.

Zeichenbeschränkung

Zeichenfolgen wie Namen64 ZeichenEs wird an der Zeit sein.

Wenn der Wert überschritten wird, wird ein Fehler angezeigt. Bitte korrigieren Sie ihn entsprechend.

Beim Importieren werden überschüssige Teile zwangsweise abgeschnitten.

Namenskonvention

Stellen Sie sicher, dass jeder Plug-In-Name, Kit-Name und Artikulationsname eindeutig ist.
