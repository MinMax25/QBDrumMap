Einstellungen

Die Einstellungsseite wird durch Klicken auf das Zahnradsymbol unten im Hamburger-Menü angezeigt.

Festlegen eines Themas

Sie können aus den folgenden Themen wählen:

  • Hell
  • Dunkel

Sie können auch eine Akzentfarbe festlegen.

Festlegen der Sprache

Im Kombinationsfeld „Sprache“ können Sie Folgendes festlegen:

  • Englisch
  • Japanisch

Änderungen werden beim nächsten Start des Programms übernommen.

Einrichten der Startseite Mit dem Kombinationsfeld „Startseite“ von

können Sie die Seite angeben, die beim Start zunächst angezeigt wird.

Änderungen werden beim nächsten Start des Programms übernommen.

Laden beim Start festlegen

  • Aktiviert: Die zuletzt geöffnete Datei wird beim nächsten Programmstart automatisch geöffnet.
  • Deaktiviert: Ein neuer Bildschirm wird angezeigt.

Festlegen des Installationsziels für Cubase

Wenn Sie die Score-Funktion von Cubase verwenden, geben Sie das Installationsziel an.

*Wenn Sie nicht über Cubase (Version 14 oder höher) verfügen oder keine Drum-Score-Anzeige benötigen, können Sie diese deaktiviert lassen.

Einstellen des Part-Namen-Wörterbuchs

Bearbeiten Sie das Notationsvariations-Wörterbuch für Drum-Part-Namen, die in „Auto Articulation Assignment“ auf der Plug-in-Seite verwendet werden.

  • Kanonischer Name: Geben Sie den auf der Seite „Teil“ festgelegten Teilenamen (offiziellen Namen) ein.
  • Aliase (durch Kommas getrennt): Geben Sie die Schreibvarianten des kanonischen Namens durch Kommas getrennt ein (z. B. „Bass Drum, BD“). Fügen Sie eine Zeile mit der Schaltfläche
  • + hinzu und löschen Sie sie, indem Sie in der ausgewählten Zeile die Entf-Taste drücken.

Dieses Wörterbuch wird verwendet, um Artikulationen automatisch festzulegen, indem Stimmen aus Tonhöhennamen abgeleitet werden. Bitte registrieren Sie sich, wenn die Drum-Parts je nach Plug-in unterschiedlich heißen (Kick / Bass Drum / BD etc.).
