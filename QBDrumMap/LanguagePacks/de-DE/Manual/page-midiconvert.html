MIDI Convert

Konvertiert MIDI-Daten (SMF).

So verwenden Sie

Wählen Sie das Basiskit aus, von dem Sie umrüsten möchten. Importieren Sie die zu konvertierende Datei über die Schaltfläche auf der rechten Seite von
Target Midi File.
Alternativ können Sie eine MIDI-Datei importieren, indem Sie sie per Drag & Drop auf die Seite ziehen. (Version 1.0.1 oder höher)
Wählen Sie das Konvertierungsziel aus der Kit-Liste auf der rechten Seite des Bildschirms aus (Mehrfachauswahl ist möglich) und klicken Sie auf die Schaltfläche „Konvertieren“.

Konvertierungsspezifikationen

Die Konvertierung erfolgt basierend auf den Drum-Map-Artikulationseinstellungen.

Tonhöhen, für die keine Artikulation angegeben ist, werden als separate Daten ausgegeben, wobei am Anfang des ursprünglichen Dateinamens ein „#“ hinzugefügt wird.

Wenn es sich bei der Konvertierungsquelle beispielsweise um Daten handelt, die auch GM-Map-Percussion enthalten, werden der Drum-Part und der Percussion-Part getrennt.

Die konvertierte Ausgabedatei wird im selben Ordner wie die Originaldatei erstellt.

Wenn das Ausgabeformat Format0 ist, wird ein Ordner mit dem ursprünglichen Dateinamen + _converted erstellt und darin eine Datei mit dem konvertierten Drum-Map-Namen.

Wenn das Ausgabeformat Format1 ist, wird eine Datei mit dem ursprünglichen Dateinamen + _converted erstellt und darin wird eine Spur mit dem konvertierten Drum-Map-Namen erstellt.

Über das Ausgabeformat

Wenn Sie Cubase verwenden, ist es am besten, Format 0 zu verwenden, da Sie einzelne Spuren in einer MIDI-Datei nicht verarbeiten können.
