Configuración

La página de configuración se muestra al hacer clic en el ícono de ajustes en la parte inferior del menú de hamburguesas.

Aviso al actualizar: Esta versión cambia el formato del archivo de configuración de JSON a TOML (Setting.toml). La configuración de versiones anteriores no se migra automáticamente. Vuelva a configurar sus preferencias después de actualizar.

Configuración de un tema

Puede elegir entre los siguientes temas:

  • Claro
  • Oscuro

También puede especificar un color de acento.

Configuración del idioma

Puede especificar lo siguiente en el cuadro combinado Idioma:

  • El inglés y el japonés están incluidos.
  • En el proyecto de código fuente, los paquetes de idioma se guardan en LanguagePacks/<locale>/. Para usarlos, copie un paquete en Languages/<locale>/, dentro de la carpeta de la aplicación.

El idioma seleccionado se activa inmediatamente. Los textos que usan enlaces de localización se actualizan; algunos elementos de la interfaz podrían actualizarse al volver a mostrarse.

Configuración de la página de inicio El cuadro combinado Página de inicio de

le permite especificar la página que se muestra inicialmente al inicio.

Los cambios se reflejarán la próxima vez que se inicie el programa.

Establecer carga al inicio

  • Comprobado: el último archivo abierto se abrirá automáticamente la próxima vez que se inicie el programa.
  • Sin marcar: Se mostrará una nueva pantalla.

Configuración del destino de instalación para Cubase

Cuando utilice la función de puntuación de Cubase, especifique el destino de instalación.

*Si no tiene Cubase (versión 14 o posterior) o no necesita mostrar la partitura de batería, puede dejarlo sin configurar.

Configuración del diccionario de nombres de partes

Edite el diccionario de variación de notación para los nombres de partes de batería utilizados en "Asignación automática de articulación" en la página del complemento.

  • Nombre canónico: ingrese el nombre de la pieza (nombre oficial) establecido en la página de la pieza.
  • Alias ​​(separados por comas): ingrese las variaciones ortográficas del nombre canónico separados por comas (por ejemplo, "Bambo, BD"). Agregue una línea con el botón
  • + y elimínela presionando la tecla Eliminar en la línea seleccionada.

Este diccionario se utiliza para establecer articulaciones automáticamente infiriendo partes a partir de los nombres de los tonos. Regístrese si las partes de batería se llaman de manera diferente (Kick / Bass Drum / BD, etc.) según el complemento.
