Este es un editor de mapas de batería utilizado en DAW (Studio One, Cubase). Requisitos del sistema

El entorno operativo es únicamente el sistema operativo Windows. Cumple con los requisitos del sistema de Windows

Studio One Pro.

Descripción general del programa

  1. Absorbe diferencias entre fuentes de sonido
    • Separando la gestión de la información de articulación que se puede utilizar común a cada fuente de sonido, es posible unificar articulaciones que eran diferentes entre fuentes de sonido.
    • Al incluir información de partitura de batería en la información de articulación, no es necesario configurar la información de partitura de la DAW individualmente.
  2. Utilizando mapas de batería comunes
    • Los datos de mapas administrados por este software se administran como un archivo json que se puede convertir a "Studio Oe" y "Cubase". Los datos del mapa
    • se pueden importar y exportar en formato TSV. Esto permite editar con un editor externo (como Excel).
    • Anteriormente, los archivos de mapas se editaban para cada fuente de sonido o paquete de expansión, pero con este software, se administran centralmente como datos JSON, lo que facilita el mantenimiento de los archivos de mapas.
    • Los formatos de archivo que se pueden importar son el archivo ".pitchlist" de "Studio One", el archivo ".drm" de "Cubase" y el archivo ".tsv" exportado por este software.
      *Solo se importa el tono de salida del mapa de Cubase.
  3. Comodidad mejorada
    • Equipado con una función que le permite realizar una prueba de sonido (escuchar) al crear un mapa de batería.
    • Se puede registrar información de cambio de programa para fuentes de sonido de diversos estándares, como GM, GM2, GS y XG. Además, dado que el número de programa registrado y los datos exclusivos del sistema se envían al editar el mapa, es posible trabajar sin operar la fuente de sonido tanto como sea posible.
