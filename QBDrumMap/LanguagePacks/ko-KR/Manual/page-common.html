목록 편집

플러그인, 파트, 아티큘레이션 각 페이지에 있는 일람 표시부의 편집에 대해서

  • 클릭으로 행 선택, 컨트롤 키 병용으로 선택 항목 추가, 시프트 키 병용으로 범위 선택
  • 선택 행이 있는 상태에서 Delete 키 누름으로 선택 행 삭제
    ※피치 리스트의 경우는 클리어
  • 상단 버튼 기능
    • +: 행 추가
    • ⇧: 선택 라인을 맨 위로 이동
    • ↑:선택한 행을 한 줄 위로 이동
    • ↓: 선택 라인을 한 줄 아래로 이동
    • ⇩: 선택 행을 마지막 꼬리로 이동
  • 셀을 더블 클릭 또는 F2 키를 눌러 편집 상태가 됩니다.

문자 수 제한

이름 등의 문자열은64자까지입니다.

초과하는 경우는 에러 표시되므로, 적절히 수정해 주십시오.

가져올 때, 초과는 강제로 잘립니다.

명명 규칙

플러그인, 키트 및 아티큘레이션 이름은 각각 고유해야 합니다.
