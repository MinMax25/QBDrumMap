설정

설정 페이지는 햄버거 메뉴 하단의 톱니바퀴 아이콘 클릭으로 표시됩니다.

업데이트 시 주의: 이 버전부터 설정 파일 형식이 JSON에서 TOML(Setting.toml)로 변경되었습니다. 이전 버전의 설정은 자동으로 이전되지 않으므로 업데이트 후 설정을 다시 입력해야 합니다.

테마 설정

다음 테마를 선택할 수 있습니다.

  • Light
  • 다크

또한 악센트 색상을 지정할 수 있습니다.

언어 설정

Language 콤보 상자에서 다음을 지정할 수 있습니다.

  • 영어와 일본어는 기본 제공됩니다.
  • 소스 프로젝트의 언어 팩은 LanguagePacks/<locale>/에 있습니다. 사용하려면 언어 팩을 앱 폴더의 Languages/<locale>/에 복사하세요.

선택한 언어는 즉시 활성화됩니다. 현지화 바인딩이 적용된 텍스트는 갱신되며, 일부 화면 요소는 다시 표시될 때 갱신될 수 있습니다.

시작 페이지 설정

Start Up Page 콤보 상자에서 시작할 때 초기에 표시되는 페이지를 지정할 수 있습니다.

변경 내용은 다음 번 프로그램 시작시 반영됩니다.

시작시 읽기 설정

  • 체크 : 마지막으로 열린 파일이 다음에 시작할 때 자동으로 열립니다.
  • 확인 없음: 새 화면이 표시됩니다.

Cubase 설치 대상 설정

Cubase 점수 기능을 사용하는 경우 설치 대상을 지정하십시오.

※ Cubase(ver14 이후)를 가지고 있지 않은 분, 또는 드럼 스코어 표시가 불필요한 분은 미설정인 채로 문제 없습니다.

부품 이름 사전 설정

플러그인 페이지의 "아티큘레이션 자동 할당"에서 사용할 드럼 부품 이름의 표기 흔들림 사전을 편집합니다.

  • Canonical Name: Part 페이지에서 설정한 부품 이름(공식 이름)을 입력합니다.
  • Aliases (comma separated): Canonical Name의 표기 흔들림을 쉼표로 구분하여 입력합니다(예: "Bass Drum,BD").
  • + 버튼으로 행을 추가, 선택 행에서 Delete 키를 눌러 삭제합니다.

이 사전은 피치 이름에서 파트를 추측하여 아티큘레이션을 자동으로 설정하는 데 사용됩니다. 플러그인에 따라 드럼 파트의 호출 방법(Kick/Bass Drum/BD 등)이 다른 경우에 등록해 주십시오.
