Editar lista

Sobre a edição da área de exibição da lista em cada página de plug-in, peça e articulação

  • Clique para selecionar uma linha, use a tecla Control para adicionar seleções, use a tecla Shift para selecionar um intervalo
  • Exclua a linha selecionada pressionando a tecla Delete enquanto houver uma linha selecionada
    *Limpar se a lista de argumentos de venda
  • Funções dos botões superiores
    • +: Adicione uma linha
    • ⇧: Move a linha selecionada para o início
    • ↑: Mover a linha selecionada uma linha para cima
    • ↓: Move a linha selecionada uma linha para baixo
    • ⇩: Move a linha selecionada para o final
  • Clique duas vezes em uma célula ou pressione a tecla F2 para entrar no modo de edição.

When you have unsaved changes

If a map has unsaved edits when you create a new map, open another file, or close the application, a confirmation appears.

  • Save: The operation continues after saving succeeds. If saving is canceled or fails, the operation is canceled.
  • Don't Save: The edits are discarded and the operation continues.
  • Cancel: The edits are kept and the operation is canceled.

Limite de caracteres

Sequências de caracteres, como nomes64 caracteresDependerá.

Se exceder, um erro será exibido, portanto corrija-o conforme apropriado.

Ao importar, as porções excedentes são truncadas à força.

Convenção de nomenclatura

Certifique-se de que cada nome de plug-in, nome de kit e nome de articulação seja exclusivo.
