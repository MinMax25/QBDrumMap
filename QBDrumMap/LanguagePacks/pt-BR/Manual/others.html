Sobre a interpolação automática de articulações

Ao converter MIDI ou criar um mapa de bateria mapeado, um mapa de articulação é criado para cada mapa de bateria e a conversão de afinação é realizada com base nessas informações.

Se não houver altura atribuída a uma articulação, uma altura alternativa será preenchida de acordo com as seguintes regras.

  1. Se a lista de articulações de cada parte de bateria estiver indefinida de cima para baixo, preencha a afinação anterior.
  2. Se a lista de articulações para cada parte de bateria estiver indefinida de baixo para cima, preencha a afinação anterior.
  3. Depois de executar 1.2. acima, se ainda estiver indefinido, preencha a altura da articulação definida como Complemento.

De acordo com as regras acima, as articulações da parte da bateria requerem pelo menos uma atribuição de afinação.
