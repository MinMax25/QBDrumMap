Conversão MIDI

Converte dados MIDI (SMF).

Como usar

Selecione o kit básico para conversão. Importe o arquivo a ser convertido usando o botão à direita do
Target Midi File.
Alternativamente, você pode importar um arquivo MIDI arrastando e soltando-o na página. (versão 1.0.1 ou posterior)
Selecione o alvo de conversão na lista de kits no lado direito da tela (múltiplas seleções são possíveis) e pressione o botão converter.

Especificações de conversão

A conversão é realizada com base nas configurações de articulação do mapa de bateria.

As alturas para as quais nenhuma articulação é especificada serão geradas como dados separados com um '#' adicionado ao início do nome do arquivo original.

Por exemplo, se a fonte de conversão for dados que também incluam percussão de mapa GM, a parte de bateria e a parte de percussão serão separadas.

O arquivo de saída convertido será criado na mesma pasta do arquivo original.

Se o formato de saída for Format0, uma pasta será criada com o nome do arquivo original + _converted, e um arquivo será criado nela com o nome do mapa de bateria convertido.

Se o formato de saída for Format1, um arquivo será criado com o nome do arquivo original + _converted, e uma trilha será criada dentro dele com o nome do mapa de bateria convertido.

Sobre o formato de saída

Se você estiver usando o Cubase, é melhor usar o formato 0, pois você não pode manipular trilhas individuais em um arquivo MIDI.
