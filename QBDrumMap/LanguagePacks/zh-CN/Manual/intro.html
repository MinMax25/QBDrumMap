简介

这是用于 DAW（Studio One、Cubase）的鼓映射编辑器。

系统要求

操作环境仅限Windows 操作系统。符合

Studio One Pro Windows 系统要求。

程序概要

  1. 吸收声源之间的差异
    • 通过分离每个声源可共用的发音信息的管理，可以统一声源之间不同的发音。
    • 通过在发音信息中包含鼓乐谱信息，无需单独设置 DAW 的乐谱信息。
  2. 利用常见的鼓映射
    • 本软件管理的映射数据作为 json 文件进行管理，可以转换为“Studio Oe”和“Cubase”。
    • 地图数据可以TSV格式导入和导出。这允许使用外部编辑器（例如 Excel）进行编辑。
    • 以前，地图文件是针对每个音源或扩展包进行编辑的，但有了这个软件，它们作为一个 JSON 数据进行集中管理，使地图文件更易于维护。
    • 可导入的文件格式为“Studio One”的“.pitchlist”文件、“Cubase”的“.drm”文件以及本软件导出的“.tsv”文件。
      *仅从 Cubase 映射导入输出音高。
  3. 提高便利性
    • 配备允许您在创建鼓映射时执行声音检查（聆听）的功能。
    • 可以注册GM、GM2、GS、XG等各种标准声源的程序变更信息。此外，由于在编辑地图时发送注册的节目编号和系统专用数据，因此可以尽可能不操作声源进行工作。
