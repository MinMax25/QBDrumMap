MIDI Convert

Convertit les données MIDI (SMF).

Comment utiliser

Sélectionnez le kit de base à partir duquel effectuer la conversion. Importez le fichier à convertir à l’aide du bouton sur le côté droit de
Target Midi File.
Alternativement, vous pouvez importer un fichier MIDI en le faisant glisser et en le déposant sur la page. (version 1.0.1 ou ultérieure)
Sélectionnez la cible de conversion dans la liste des kits sur le côté droit de l'écran (plusieurs sélections sont possibles) et appuyez sur le bouton de conversion. Spécifications de conversion

La conversion

est effectuée en fonction des paramètres d'articulation de la mappe de batterie.

Les hauteurs pour lesquelles aucune articulation n'est spécifiée seront sorties sous forme de données séparées avec un « # » ajouté au début du nom du fichier d'origine.

Par exemple, si la source de conversion est constituée de données incluant également des percussions de carte GM, la partie batterie et la partie percussion seront séparées.

Le fichier de sortie converti sera créé dans le même dossier que le fichier d'origine.

Si le format de sortie est Format0, un dossier sera créé avec le nom de fichier d'origine + _converted, et un fichier y sera créé avec le nom de Drum Map converti.

Si le format de sortie est Format1, un fichier sera créé avec le nom de fichier d'origine + _converti, et une piste sera créée à l'intérieur avec le nom de Drum Map converti.

À propos du format de sortie

Si vous utilisez Cubase, il est préférable d'utiliser le format 0 car vous ne pouvez pas gérer des pistes individuelles dans un fichier MIDI.
