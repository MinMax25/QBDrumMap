Introduction

Il s'agit d'un éditeur de drum map utilisé dans DAW (Studio One, Cubase). Configuration système requise pour

L'environnement d'exploitation est le système d'exploitation Windows uniquement. Conforme à la configuration système requise pour

Studio One Pro Windows.

Présentation du programme

  1. Absorbe les différences entre les sources sonores
    • En séparant la gestion des informations d'articulation pouvant être utilisées communes à chaque source sonore, il est possible d'unifier les articulations qui étaient différentes entre les sources sonores.
    • En incluant les informations de partition de batterie dans les informations d'articulation, il n'est pas nécessaire de définir les informations de partition de la DAW individuellement.
  2. Utilisation de Drum Maps courantes
    • Les données cartographiques gérées par ce logiciel sont gérées sous forme de fichier json qui peut être converti en « Studio Oe » et « Cubase ». Les données cartographiques
    • peuvent être importées et exportées au format TSV. Cela permet l'édition avec un éditeur externe (tel qu'Excel).
    • Auparavant, les fichiers cartographiques étaient édités pour chaque source sonore ou pack d'extension, mais avec ce logiciel, ils sont gérés de manière centralisée comme une seule donnée JSON, ce qui facilite la maintenance des fichiers cartographiques.
    • Les formats de fichiers pouvant être importés sont le fichier ".pitchlist" de "Studio One", le fichier ".drm" de "Cubase" et le fichier ".tsv" exporté par ce logiciel.
      *Seul le pitch de sortie est importé de la map Cubase.
  3. Confort amélioré
    • Équipé d'une fonction qui vous permet d'effectuer une vérification du son (écoute) lors de la création d'une drum map.
    • Les informations de changement de programme pour les sources sonores de diverses normes telles que GM, GM2, GS et XG peuvent être enregistrées. De plus, étant donné que le numéro de programme enregistré et les données exclusives au système sont envoyés lors de l'édition de la carte, il est possible de travailler sans utiliser autant que possible la source sonore.
