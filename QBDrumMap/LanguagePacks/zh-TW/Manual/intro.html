這是用於 DAW（Studio One、Cubase）的鼓映射編輯器。

系統要求

操作環境僅為Windows 作業系統。符合

Studio One Pro Windows 系統要求。

程式摘要

  1. 吸收聲源之間的差異
    • 透過分離每個聲源可共用的發音訊息的管理，可以統一聲源之間不同的發音。
    • 透過在發音訊息中包含鼓樂譜訊息，無需單獨設定 DAW 的樂譜訊息。
  2. 利用常見的鼓映射
    • 本軟體管理的映射資料作為 json 檔案進行管理，可轉換為「Studio Oe」和「Cubase」。
    • 地圖資料可以TSV格式匯入和匯出。這允許使用外部編輯器（例如 Excel）進行編輯。
    • 以前，地圖檔案是針對每個音源或擴充包進行編輯的，但有了這個軟體，它們作為一個 JSON 資料進行集中管理，使地圖檔案更易於維護。
    • 可匯入的檔案格式為「Studio One」的「.pitchlist」檔案、「Cubase」的「.drm」檔案以及本軟體匯出的「.tsv」檔案。
      *僅從 Cubase 映射匯入輸出音高。
  3. 提高便利性
    • 配備可讓您在建立鼓映射時執行聲音檢查（聆聽）的功能。
    • 可以註冊GM、GM2、GS、XG等各種標準聲源的程式變更資訊。此外，由於在編輯地圖時發送註冊的節目編號和系統專用數據，因此可以盡可能不操作聲音來源進行工作。
