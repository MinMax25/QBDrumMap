소개

DAW(Studio One, Cubase)에서 사용하는 드럼 맵 편집기입니다.

시스템 요구 사항

운영 환경은 Windows OS 전용입니다.

Studio One Pro Windows 시스템 요구 사항을 준수합니다.

프로그램 개요

  1. 음원별 차이를 흡수
    • 각 음원 공통으로 사용 가능한 아티큘레이션 정보의 관리를 독립시킴으로써, 음원간에 제대로 된 아티큘레이션을 통일하는 것을 가능하게 합니다.
    • 아티큘레이션 정보에 드럼 스코어 정보를 제공함으로써 DAW의 스코어 정보를 개별적으로 설정하지 않아도 됩니다.
  2. 공통 드럼 맵의 활용
    • 본 소프트웨어로 관리하는 맵 데이터는 "Studio Oe", "Cubase"로의 상호 변환 가능한 형태의 json 파일로서 관리됩니다.
    • 맵 데이터는 TSV 형식을 가져오고 내보낼 수 있습니다. 이렇게하면 외부 편집기 (Excel 등)에서 편집 할 수 있습니다.
    • 종래, 음원이나 확장 팩마다 편집하고 있던 맵 파일은, 본소프트에서는 1개의 json 데이터로서 집중 관리되기 때문에 맵 파일의 보수성이 오릅니다.
    • 가져올 수 있는 파일 형식은 "Studio One"의 ".pitchlist" 파일, "Cubase"의 ".drm" 파일, 본 소프트웨어로 내보낸 ".tsv" 파일입니다.
      ※Cubase의 맵에서는 출력 피치만을 가져옵니다.
  3. 편의성 향상
    • 드럼 맵 작성시에 사운드 체크(시청)를 실시할 수 있는 기능을 갖추고 있습니다.
    • GM, GM2, GS, XG 등 각 규격의 음원의 프로그램 변경 정보가 등록 가능합니다. 또, 맵 편집시에는 등록된 프로그램№ 및 시스템 익스클루시브 데이터를 송신하기 때문에, 최대한 음원측의 조작을 하지 않고 작업하는 것이 가능합니다.
