플러그인

드럼 맵을 편집합니다.

드럼 맵 편집

플러그인, 키트 정보를 설정합니다.

  • 플러그인 목록에서 플러그인을 선택합니다. 플러그인이 없으면 플러그인을 추가합니다.
  • 키트 목록에서 키트를 선택합니다. 키트가 없으면 키트를 추가합니다.
  • 피치 목록에서 맵 설정을 수행합니다.

피치리스트

VST(드럼 음원)에 정의된 드럼 맵 정보를 설정합니다.

  • 이름
    • 피치 이름을 입력합니다. 공백의 경우는 피치 미설정이 됩니다.
  • 아티큘레이션
    • 검색 버튼에서 아티큘레이션 선택 화면을 열고 해당 항목을 선택합니다.
  • 분리기
    • 콤보 박스에서 해당하는 것을 선택합니다.

필터

피치명, 아티큘레이션명에 의해 좁히기를 실시합니다.

별표(*)에 의한 와일드카드 지정을 할 수 있습니다.

  • 지정하지 않으면 정확히 일치
  • 키워드의 시작 부분에 붙인 경우 후방 일치
  • 키워드 끝에 붙인 경우 앞으로 일치
  • 키워드 앞뒤에 붙인 경우 부분 일치

정렬

  • 해당 피치 행의 각 항목을 입력합니다.
  • 열 제목을 클릭하여 정렬 순서를 변경할 수 있습니다.
    • 첫 번째 클릭으로 오름차순, 두 번째로 내림차순, 세 번째로 초기 상태로 돌아갑니다.
    • 정렬된 상태에서는 일부 편집 기능에 제한이 있습니다. 편집하려면 초기 상태로 되돌립니다.

사운드 체크

피치 리스트 각 행에 있는 스피커 아이콘을 클릭하면 해당 행의 노트 온/오프 메시지가 MIDI 포트로 전송됩니다.

컨텍스트 메뉴

피치 목록의 오른쪽 클릭으로 표시됩니다.

  • 아티큘레이션 맵 표시
  • 드럼 맵 내보내기
    • Studio One
    • Cubase
    • .tsv 텍스트
  • 드럼 맵 가져오기 (.pitchlist, .drm, .tsv)
  • 피치리스트 정렬
    • 피치순으로 정렬
    • 앞으로 들어가다
  • 다른 맵에서 아티큘레이션 복사
  • 아티큘레이션 자동 할당
    • 맵 데이터의 아티큘레이션(파트명 사전, 그 외 Kit의 설정, 유사도 매칭)을 기초로, 미설정의 피치에 아티큘레이션을 자동 설정합니다.
    • GM/GS/XG 플러그인의 경우, 타악기 용도의 표준 노트는 자동 설정의 대상에서 제외됩니다.
    • 이름은 있지만 아티큘레이션이 정해지지 않은 피치에는 Separator에 「Separate」가 설정됩니다.
  • 아티큘레이션 및 세퍼레이터 클리어
    • 키트의 모든 피치의 아티큘레이션과 분리기를 설정되지 않은 상태로 되돌립니다(피치 이름은 변경되지 않음).

아티큘레이션 맵

컨텍스트 메뉴에서 호출로 표시됩니다. 어떤 피치가 어떤 아티큘레이션에 할당되었는지를 여기에서 확인할 수 있습니다.

아티큘레이션에 연결된 피치가 표시됩니다.

Sub 열의 체크는 자동 보간된 피치입니다.

플러그인 옵션

  • Sound Check Velocity
    • 사운드 체크 버튼을 누를 때 출력되는 노트 온의 벨로시티 값을 설정합니다.
  • 입력 고정
    • MIDI In Fixed Pitch를 활성화합니다.
  • MIDI In Device
    • MIDI 키보드가 연결된 포트를 선택합니다. 필요하지 않은 경우 공백을 선택합니다. 사용 가능한 경우 "Connected", 사용할 수없는 경우 "Not Connected"로 표시됩니다.
  • MIDI In Fixed Pitch
    • 접수할 MIDI 키보드의 노트 온/오프 메시지의 피치를 지정합니다.
      이 값을 지정하고 "Input Fixed"를 활성화하면, MIDI 키보드의 입력이 피치 리스트에서 선택한 노트 온 오프 메시지로 변환되어 출력됩니다.
  • MIDI Out Device
    • MIDI 메시지의 출력 대상을 선택합니다. 사용 가능한 경우 "Connected", 사용할 수없는 경우 "Not Connected"로 표시됩니다.
