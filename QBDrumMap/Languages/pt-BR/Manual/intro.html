Introdução

Este é um editor de drum map usado em DAW (Studio One, Cubase).

Requisitos do sistema

O ambiente operacional é apenas o sistema operacional Windows. Está em conformidade com os requisitos de sistema do

Studio One Pro Windows.

Visão geral do programa

  1. Absorve diferenças entre fontes sonoras
    • Ao separar o gerenciamento das informações de articulação que podem ser utilizadas comuns a cada fonte sonora, é possível unificar articulações que eram diferentes entre fontes sonoras.
    • Ao incluir informações de partitura de bateria nas informações de articulação, não há necessidade de definir as informações de partitura do DAW individualmente.
  2. Utilizando mapas de bateria comuns
    • Os dados do mapa gerenciados por este software são gerenciados como um arquivo json que pode ser convertido em "Studio Oe" e "Cubase". Os dados do mapa
    • podem ser importados e exportados no formato TSV. Isto permite a edição com um editor externo (como o Excel).
    • Anteriormente, os arquivos de mapa eram editados para cada fonte de som ou pacote de expansão, mas com este software, eles são gerenciados centralmente como um dado JSON, facilitando a manutenção dos arquivos de mapa.
    • Os formatos de arquivo que podem ser importados são o arquivo ".pitchlist" do "Studio One", o arquivo ".drm" do "Cubase" e o arquivo ".tsv" exportado por este software.
      *Apenas a afinação de saída é importada do mapa Cubase.
  3. Maior conveniência
    • Equipado com uma função que permite realizar uma verificação de som (ouvir) ao criar um mapa de bateria.
    • As informações de alteração de programa para fontes de som de vários padrões, como GM, GM2, GS e XG, podem ser registradas. Além disso, como o número do programa cadastrado e os dados exclusivos do sistema são enviados na edição do mapa, é possível trabalhar ao máximo sem operar a fonte sonora.
