Exportar

Exporta o mapa de bateria.

Como usar

Selecione o destino de exportação na lista de kits no lado direito da tela (são possíveis múltiplas seleções), Pressione o botão de exportação desejado. Selecione o local de armazenamento na caixa de diálogo de seleção de pasta que aparece. A pasta selecionada é gravada no arquivo de configurações e se torna a pasta de seleção padrão na próxima vez que você exportar.

Usar Articulação Se

Usar Nome da Afinação da Articulação estiver marcado, o nome da articulação será usado preferencialmente para o nome da afinação.

Ao exportar um mapa de bateria normal, você pode especificar se deseja ou não usar articulação em Usar articulação ao exportar. Se você optar por não usar a articulação

, o conteúdo exibido na lista de afinações será exibido como está. Se você selecionar Usar articulação

, a ordem de classificação será determinada pela articulação vinculada, e não pelo conteúdo exibido na lista de alturas.

As informações da partitura da bateria e o esquema de cores serão exibidos somente se você selecionar Usar articulação. (Não há informações sobre esquema de cores para o Cubase)

Sobre o nome do arquivo

O nome do arquivo será o nome do kit.Extensão. Se já existir um arquivo com o mesmo nome, ele será sobrescrito e substituído.

A lista de pitches para o Studio One, o mapa de bateria para o Cubase e o texto tsv são exibidos na pasta de nomes do plug-in.

Tipo de arquivo

Os arquivos que podem ser exportados são os seguintes.

  • Mapa de bateria normal
    • Lista de tons para Studio One
    • Mapa de bateria para Cubase
  • Mapa de bateria mapeado
    • Mapa de bateria para Cubase
    • Modelo para Note Mapper
  • Outros
    • tsv text

Ao exportar um mapa de bateria mapeado, selecione o drum map (kit) como fonte.
