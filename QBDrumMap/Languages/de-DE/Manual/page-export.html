Export

Exportiert die Drum-Map.

So verwenden Sie

Wählen Sie das Exportziel aus der Kit-Liste auf der rechten Seite des Bildschirms aus (Mehrfachauswahl möglich). Drücken Sie den gewünschten Export-Button. Wählen Sie im erscheinenden Ordnerauswahldialog den Speicherort aus. Der ausgewählte Ordner wird in der Einstellungsdatei aufgezeichnet und wird beim nächsten Export zum Standardauswahlordner.

Artikulation verwenden Wenn

Tonhöhennamen der Artikulation verwenden aktiviert ist, wird der Artikulationsname bevorzugt als Tonhöhenname verwendet.

Beim Exportieren einer normalen Drum-Map können Sie unter „Artikulation beim Exportieren verwenden“ angeben, ob Artikulation verwendet werden soll oder nicht. Wenn Sie die

-Artikulation nicht verwenden, werden die in der Tonhöhenliste angezeigten Inhalte unverändert ausgegeben. Wenn Sie

-Artikulation verwenden auswählen, wird die Sortierreihenfolge durch die verknüpfte Artikulation und nicht durch den angezeigten Inhalt der Tonhöhenliste bestimmt.

Drum-Score-Informationen und Farbschema werden nur ausgegeben, wenn Sie Artikulation verwenden auswählen. (Es gibt keine Informationen zum Farbschema für Cubase)

Über den Dateinamen

Der Dateiname ist der Kit-Name.Erweiterung. Existiert bereits eine Datei mit demselben Namen, wird diese überschrieben und ersetzt.

Pitch-Liste für Studio One, Drum-Map für Cubase und TSV-Text werden im Plug-In-Namensordner ausgegeben.

Dateityp

Folgende Dateien können exportiert werden.

  • Normale Drum-Map
    • Pitch-Liste für Studio One
    • Drum-Map für Cubase
  • Zugeordnete Drum-Map
    • Drum-Map für Cubase
    • Vorlage für Note Mapper
  • Sonstiges
    • tsv-Text

Wählen Sie beim Exportieren einer gemappten Drum-Map die zu erstellende Drum-Map (Kit) aus die Quelle.
