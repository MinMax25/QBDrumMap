Articulation

Set the sorting order when creating a drum map.

About the display order

If "Use articulations" is checked when exporting the drum map

The drum maps will be grouped according to the following rules, and the groups will be sorted in descending order of articulation pitch.

  1. Articulation is specified but separator is not specified.
  2. Articulation is not specified and Separate is specified.
  3. Articulation is specified and Separate is specified.
  4. articulation is specified and Not Loaded is specified.
  5. Articulation is specified and Duplicate is specified.
  6. Articulation is not specified and separator is not specified.

If there is an undefined minimum pitch between 2. and 3., a separator ("==========") will be automatically interpolated.

If "Use articulations" is not checked when exporting the drum map

The pitch list order will be applied as is.
