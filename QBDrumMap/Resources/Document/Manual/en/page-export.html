Export

Exports the drum map.

How to use

Select the export target from the kit list on the right side of the screen (multiple selections possible), Press the desired export button. Select the storage location in the folder selection dialog that appears. The selected folder is recorded in the settings file and becomes the default selection folder the next time you export.

Use Articulation If

Use Articulation Pitch Name is checked, the articulation name will be used preferentially for the pitch name.

When exporting a normal drum map, you can specify whether or not to use articulation in Use Articulation When Exporting. If you select not to use the

articulation, the contents displayed in the pitch list will be output as is. If you select Use

articulation, the sorting order will be determined by the linked articulation rather than the displayed contents of the pitch list.

Drum score information and color scheme will be output only if you select Use articulation. (There is no color scheme information for Cubase)

About the file name

The file name will be the kit name.Extension. If a file with the same name already exists, it will be overwritten and replaced.

Pitch list for Studio One, drum map for Cubase, and tsv text are output under the plug-in name folder.

File type

The files that can be exported are as follows.

  • Normal drum map
    • Pitch list for Studio One
    • Drum map for Cubase
  • Mapped drum map
    • Drum map for Cubase
    • Template for Note Mapper
  • Others
    • tsv text

When exporting a mapped drum map, select the drum map (kit) to be the source.

About the CSV for QB Drummer

In the CSV for QB Drummer, each articulation is assigned a sequential number dedicated to the CSV.

Changing the articulation configuration or order of the drum map may change these numbers, so combining CSV files from before and after a change may not convert correctly. After changing the drum map, re-export the CSV of the kits you use.
