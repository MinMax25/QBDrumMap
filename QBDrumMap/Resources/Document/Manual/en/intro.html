Introduction

This is a drum map editor used in DAW (Studio One, Cubase).

System Requirements

Operating environment is Windows OS only. Complies with

Studio One Pro Windows system requirements.

Program Overview

  1. Absorbs differences between sound sources
    • By separating the management of articulation information that can be used common to each sound source, it is possible to unify articulations that were different between sound sources.
    • By including drum score information in the articulation information, there is no need to set the DAW's score information individually.
  2. Utilizing common drum maps
    • The map data managed by this software is managed as a json file that can be converted to "Studio Oe" and "Cubase".
    • Map data can be imported and exported in TSV format. This allows editing with an external editor (such as Excel).
    • Previously, map files were edited for each sound source or expansion pack, but with this software, they are centrally managed as one JSON data, making map files easier to maintain.
    • The file formats that can be imported are the ".pitchlist" file of "Studio One", the ".drm" file of "Cubase", and the ".tsv" file exported by this software.
      *Only the output pitch is imported from the Cubase map.
  3. Improved convenience
    • Equipped with a function that allows you to perform a sound check (listening) when creating a drum map.
    • Program change information for sound sources of various standards such as GM, GM2, GS, and XG can be registered. In addition, since the registered program number and system exclusive data are sent when editing the map, it is possible to work without operating the sound source as much as possible.
