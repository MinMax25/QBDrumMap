Parts

Edit drum parts and articulations.

Edit drum parts

  • Select a part from the parts list. If the part does not exist, add the part.
  • Make settings in the articulation list.

Articulation List Register the articulations used in the

part.

  • Name
    • Enter the articulation name.
  • Alternative Articulation
    • Use this specified articulation if no articulation is used in the drum map.

Score Configure the score display settings for the

part. Click the header section of the score to open/close it. If you do not need the drum score function, you can leave the default values ​​as is.

To set the Cubase score, you need to set the Cubase installation destination on the settings screen.
