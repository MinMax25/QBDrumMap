Settings

The settings page is displayed by clicking the gear icon at the bottom of the hamburger menu.

Important notice for upgrading: This release changes the settings file format from JSON to TOML. Settings from previous versions are not migrated automatically. Please configure your settings again after upgrading.

Setting a Theme

You can choose from the following themes:

  • Light
  • Dark

You can also specify an accent color.

Setting the language

The Language combo box supports these options:

  • English and Japanese are built in.
  • Other languages are available when a language pack is placed under Languages/<culture-code>/ in the application folder.

The selected language is applied to the application. Available additional languages depend on the installed language packs.

Setting the startup page The

Start Up Page combo box allows you to specify the page that is initially displayed at startup.

Changes will be reflected the next time the program is started.

Set loading at startup

  • Checked: The last opened file will be automatically opened the next time the program is started.
  • Unchecked: A new screen will be displayed.

Setting the installation destination for Cubase

When using Cubase's score function, specify the installation destination.

*If you do not have Cubase (version 14 or later) or do not need drum score display, you can leave it unset.

Setting the part name dictionary

Edit the notation variation dictionary for drum part names used in "Auto Articulation Assignment" on the plug-in page.

  • Canonical Name: Enter the part name (official name) set on the Part page.
  • Aliases (comma separated): Enter the spelling variations of the Canonical Name separated by commas (e.g. "Bass Drum,BD"). Add a line with the
  • + button, and delete it by pressing the Delete key on the selected line.

This dictionary is used to automatically set articulations by inferring parts from pitch names. Please register if the drum parts are called differently (Kick / Bass Drum / BD etc.) depending on the plug-in.
