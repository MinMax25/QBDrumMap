Edit list

About editing the list display area on each plug-in, part, and articulation page

  • Click to select a line, use the control key to add selections, use the shift key to select a range
  • Delete the selected line by pressing the Delete key while there is a selected line
    *Clear if pitch list
  • Top button functions
    • +: Add a line
    • ⇧: Move the selected line to the beginning
    • ↑: Move the selected line up one line
    • ↓: Move the selected line down one line
    • ⇩: Move the selected line to the end
  • Double-click a cell or press the F2 key to enter editing mode.
