About automatic interpolation of articulations

When converting MIDI or creating a mapped drum map, an articulation map is created for each drum map, and pitch conversion is performed based on that information.

If there is no pitch assigned to an articulation, an alternate pitch will be filled in according to the following rules.

  1. If the articulation list for each drum part is undefined from the top to the bottom, fill in the previous pitch.
  2. If the articulation list for each drum part is undefined from the bottom to the top, fill in the previous pitch.
  3. After executing 1.2. above, if it is still undefined, fill in the pitch of the articulation set to Complement.

According to the above rules, drum part articulations require at least one pitch assignment.
