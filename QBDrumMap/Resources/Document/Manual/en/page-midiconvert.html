MIDI Convert

Converts MIDI data (SMF).

How to use

Select the base kit to convert from. Import the file to be converted using the button on the right side of
Target Midi File.
Alternatively, you can import a MIDI file by dragging and dropping it onto the page. (ver 1.0.1 or later)
Select the conversion target from the kit list on the right side of the screen (multiple selections are possible) and press the convert button.

Conversion specifications

Conversion is performed based on the drum map articulation settings.

Pitches for which no articulation is specified will be output as separate data with a '#' added to the beginning of the original file name.

For example, if the conversion source is data that also includes GM map percussion, the drum part and percussion part will be separated.

The converted output file will be created in the same folder as the original file.

For Format 0, output is written to a folder named after the original file with " Converted" appended. The folder is deleted and recreated if it already exists, which removes its contents. Move any files you need to keep before converting.

For Format 1, output is written to a file named after the original file with " Converted.mid" appended, with a track for each target kit.

About the output format

If you are using Cubase, it is best to use Format 0 since you cannot handle individual tracks in a MIDI file.
